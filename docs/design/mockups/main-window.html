Main window, horizontal tabs

The default layout (UI-018): tab strip, toolbar and the quiet New Tab page (UI-022). Surfaces S-WIN-01, S-WIN-03, S-WIN-07 and S-WEB-01 in the inventory.

Tab titles, shortcuts and the profile initial are sample content for layout. The right end of the tab strip is left empty on purpose: on Windows the OS caption buttons sit there. The New Tab page makes no network request until you type, and has no feed or sponsored tiles.

Tab states

State is shown by shape and text as well as colour. A suspended tab keeps its title and position; its favicon sits in a dashed ring and its accessible name says it is suspended (ENG-019).
